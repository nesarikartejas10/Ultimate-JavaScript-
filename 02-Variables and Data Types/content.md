# Rules for Variables

✅ Legal Name

1. use camel case or snake case
2. numbers are allowed in middle and last
3. $ and \_ are allowed in start, middle and last of variable name

❌ Illegal Name

1. spaces are not allowed
2. numbers are not allowed at start
3. special characters are not allowed except $ and \_
4. reserved keywords are not allowed

# Data Types

1.  Primitive Data Types

- primitive data types ko hum change nhi kr skte
- store single value
- Examples: ahmed, ahmed is my name, 12, 9.88
- Primitive => String, Number, Boolean, null, undefined, bigint, Symbol

2. Non-Primitive Data Types (Reference or Complex)

- non-primitive data types ko hum change kr skte hain
- store collection of data
- {}, (), []
- Examples: [20, 10, 30, 9], {name: "ahmed", age: 20}
- non-primitive => array, object, function
