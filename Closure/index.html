Introduction of Closure

Closure is the combination of a function bundled together with its lexical environment. Closure gives you access to an outer function scope from an inner function.

function parent(){
        let a = 'Hello';
        function child(){
            console.log(a);
        }
        return child;
    }
    
    const result = parent();
    result();

In this above example child function which creates a clouser with scope of the parent function. So here parent function not only return the child function also return the variable accessed by child function.
